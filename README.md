# Нейронная сеть: x1 × x2 (и другие функции)

## ▶ [Открыть нейросеть в браузере](https://eremin-andrey.github.io/neural-net-playground/)

Работает сразу, без установки: обучение, анимация, таблица расчёта и 3D-график — всё в одной странице
([`нейросеть.html`](нейросеть.html), чистые HTML + CSS + JavaScript).

[![Нейросеть учит кольцо с подсказкой r²](docs/screenshot.png)](https://eremin-andrey.github.io/neural-net-playground/)

---

Простая нейронная сеть на чистом Python (без numpy) учится функции двух чисел.
Входы x1, x2 берутся из диапазона **0..1** или **−1..+1** (переключатель на странице, `--domain 01 / pm1` в `train.py`).
По умолчанию — умножение на 0..1, а также можно выбрать:

| Ключ | На входах 0..1 | На входах −1..+1 | Комментарий |
|---|---|---|---|
| `mul` | x1 × x2 | x1 × x2 | умножение (по умолчанию) |
| `add` | x1 + x2 | x1 + x2 | ответ от 0 до 2 / от −2 до 2 |
| `div` | x1 / (1 + x2) | x1 / (2 + x2) | знаменатель сдвинут, чтобы не делить на ноль |
| `xor` | (x1>0.5) XOR (x2>0.5) | (x1>0) XOR (x2>0) | «ступенька»: трудна для сети, учится медленно (lr 0.05–0.1, тысячи эпох) |
| `absdiff` | \|x1 − x2\| | \|x1 − x2\| | «гладкий XOR», учится легко |
| `pow` | x1 ^ x2 | — | степень; 0⁰ = 1, у оси x1 = 0 резкий край — там ошибка больше (до ~0.1). На −1..+1 не определена: (−0.5)^0.5 — комплексное число, 0^(−0.5) — бесконечность |
| `exp` | e ^ x2 | e ^ x2 | зависит только от x2 — сеть учится не обращать внимания на x1 |
| `hat` | sin(5r) / (5r) | то же | «сомбреро»: горка и круговые волны, r = √(x1² + x2²); выучивается |
| `egg` | sin(πx1) · cos(πx2) | то же | «яичная коробка»: холмы и впадины; выучивается |
| `ring` | e^(−(10·(r − 0.6))²) | то же | «кольцо» радиуса 0.6: маленькая сеть почти не учится — пример предела |

Экзотические функции (`hat`, `egg`, `ring`) интереснее на входах −1..+1: на 0..1 видна только четверть картины.

### Подсказка r²

Галочка «подсказка: третий вход r² = x1² + x2²» (или `train.py --r2`) добавляет сети третий входной нейрон —
квадрат расстояния до центра. «Круглым» функциям это резко помогает, остальным — нет:

| Функция (входы −1..+1, 1500 эпох) | без подсказки | с подсказкой |
|---|---|---|
| кольцо | MSE ~0.08 (почти не учится) | ~0.002 |
| сомбреро | ~0.006 | ~0.0001 |
| умножение | ~0.00006 | ~0.0002 (лишний вход только мешает) |

Это пример конструирования признаков (feature engineering): от того, *что* подать на вход, задача
может стать из почти невыполнимой простой. «Честная» альтернатива — второй скрытый слой с функцией tanh
(в опытах снижал ошибку на кольце до ~0.006–0.009), но в проекте он пока не реализован.

Архитектура: **2 входа → 8 скрытых нейронов (sigmoid) → 1 выход**.
Обучение — обратное распространение ошибки (backpropagation) и градиентный спуск.

## Файлы

| Файл | Что делает |
|---|---|
| `network.py` | Сама нейросеть: прямой проход, обучение, сохранение/загрузка весов |
| `train.py` | Обучение в терминале, сохраняет веса в `weights.json` / `weights_<функция>[_pm1][_r2].json` |
| `web_app.py` | Локальный сервер: обучает сеть и показывает всё в браузере |
| `web/index.html` | Страница визуализации (для сервера) |
| `нейросеть.html` | Та же страница целиком на HTML + CSS + JavaScript, работает без сервера |
| `index.html` | Перенаправляет на `нейросеть.html` — короткий адрес для GitHub Pages |

## Одна страница без сервера: `нейросеть.html`

Самый простой способ — открыть **`нейросеть.html`** двойным щелчком. Python, сервер и интернет не нужны,
файл можно переслать кому угодно. Внутри то же самое, что в версии с сервером (все функции, диапазоны,
подсказка r², анимация, таблица расчёта, 3D-график), только сеть обучается прямо в браузере — в десятки раз быстрее.

- **Готовые сети** — встроенные обученные веса: кольцо с подсказкой r², умножение (`weights.json`), XOR-ступенька с r².
- **Сохранить веса** — скачивает файл `.json` (тот же формат, что у Python-версии) и запоминает его в браузере;
  **Загрузить веса** — берёт запомненное в браузере; **Открыть файл…** — загружает любой файл весов,
  в том числе созданный `train.py` или `web_app.py`.
- Последняя сеть запоминается при закрытии страницы и восстанавливается при открытии (график ошибки — нет).

Расчёты JavaScript-версии совпадают с Python до последнего знака на одних и тех же весах.
Страница — «снимок» `web/index.html`: изменения в версии с сервером в неё сами не попадают.

## Запуск версии с сервером

Визуализация (откроется браузер, адрес http://127.0.0.1:8765):

    python3 web_app.py

Остановить сервер — `Ctrl+C` в терминале.

Обучение без графики:

    python3 train.py                     # по умолчанию 1500 эпох, lr=0.5
    python3 train.py --epochs 3000 --hidden 12
    python3 train.py --func add          # другая функция → weights_add.json
    python3 train.py --func mul --domain pm1   # входы −1..+1 → weights_mul_pm1.json
    python3 train.py --func ring --domain pm1 --r2 --lr 0.1   # с подсказкой r² → weights_ring_pm1_r2.json

## Как пользоваться

**Вкладка «Обучение»** — выберите диапазон входов и функцию (сеть при этом сбрасывается),
нажмите «▶ Старт» и смотрите:
- схема сети: синие связи — положительные веса, красные — отрицательные, толщина — величина;
- график ошибки MSE (Mean Squared Error — среднеквадратичная ошибка) в логарифмической шкале;
- три карты: правильный ответ, ответ сети и их разница (красное — где сеть ошибается).
- **объёмный график** z = f(x1, x2): мышью можно вращать, колесом — менять наклон, «↺ Вид» — исходный ракурс.
  Режимы: только функция, только ответ сети или обе сразу (функция — тонкой сеткой, ответ сети — поверхностью),
  во время обучения видно, как поверхность сети «выгибается» под функцию.

Ползунок «скорость обучения» — размер шага градиентного спуска (слишком большой — ошибка «разойдётся»).
«Эпох за шаг» — ускоряет анимацию.

**Вкладка «Работа»** — двигайте ползунки x1 и x2: сеть сразу считает ответ,
показывает точное значение, ошибку и активацию каждого нейрона.
- **Проход сигнала** — анимация: от входов к скрытым нейронам бегут точки
  (размер — величина вклада вес × значение, цвет — знак), нейроны «загораются»,
  затем сигнал идёт к выходу. Запускается кнопкой и автоматически после смены входов
  (галочка «при смене входов»).
- **Объёмный график** — тот же, что на «Обучении», плюс белая точка: ответ сети в текущих x1, x2,
  от неё пунктир вниз до «пола».
- **Таблица расчёта** — весь счёт сети по шагам для каждого скрытого нейрона:
  w₁·x1, w₂·x2, смещение b, сумма z, активация h = σ(z), выходной вес и вклад h·w_вых;
  внизу — сумма вкладов + смещение выхода = ответ сети. Во время анимации подсвечиваются
  столбцы, которые сейчас считаются.

Кнопки «Сохранить / Загрузить веса» работают с файлом выбранной функции и диапазона:
`weights.json` для умножения на 0..1, `weights_<функция>.json` для остальных на 0..1
и `weights_<функция>_pm1.json` для входов −1..+1; с подсказкой r² к имени добавляется `_r2`
(их же создаёт `train.py --func … --domain … [--r2]`).
