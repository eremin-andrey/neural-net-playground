Расчёт по нейронной сети для текущих x1, x2

Каждый скрытый нейрон: z = w₁·x1 + w₂·x2 + b, затем h = σ(z) = 1 / (1 + e−z). Выход: y = Σ h·wвых + bвых. Под каждым числом — как оно получено.
